# Framework Change & Future Plans

Since the last post I have come up with a clearer framework for how the software will run. <br>
Due to limited file uploaded sizes, drivers will be downloaded through preset links. <br>
<br>
To guarantee your device has access to a network connection to download drivers, network drivers will be bundled with the software. This is so that if you don't have network to connect to the internet to then let the software download more drivers, it will install the network drivers offline then it will install the other selected drivers through the web.
<br>
The reason for this idea change is to optimize the software as much as possible while still offering the same functionality. 

<h4>Example of what it may look like:</h4>
<ol>
  <li>Launch the software.</li>
  <li>Select the distro you are using.</li>
  <li>In the background it will check whether or not your device has functioning network drivers.</li>
  <li>If it sees drivers, it will take you to the main menu.</li>
  <li>If it does not see working drivers, it will install the network drivers locally for the distro you've selected.</li>
  <li>Once on the main menu, you will select the driver(s) you want to install.</li>
  <li>The software will then pull the drivers from the web and install them to your system.</li>
  <li>Once done installing the drivers, it will alert you of the completion.</li>
</ol>
